# hack-81f437ae-3-da-gang

**TaskUp — понятные задачи бизнеса и открытый выбор студенческих команд.**

Стартовый проект команды 3 da gang для AI Sana. Бизнес описывает задачу, улучшает
карточку и её рейтинг, публикует в каталоге, получает отклики и выбирает команду.
Рейтинг относится к качеству описания, а не к студентам. Автоматического назначения нет.

## Быстрый старт

Нужен Node.js 22 или новее. Внешних зависимостей и ключей API нет.

```sh
npm start
```

Откройте http://localhost:3000. Проверка сценария: `npm test`.
Для разработки с перезапуском сервера: `npm run dev`.

## Структура

```text
src/
  server.mjs           # HTTP API и раздача интерфейса
  domain/tasks.mjs      # оценка качества, публикация, отклики, выбор команды
  storage/json-store.mjs # локальное сохранение данных
public/
  index.html           # страницы прототипа в одном интерфейсе
  app.js               # формы бизнеса, каталог, отклики
  styles.css           # адаптивное оформление
tests/
  workflow.test.mjs     # сквозной сценарий и ограничения
docs/
  architecture.md      # модель данных, API, границы прототипа
  roadmap.md           # план на 5 часов и распределение работы
data/                  # локальные данные, исключены из Git
```

## Что уже работает

- Создание и редактирование черновика с шестью полями задачи.
- Рейтинг 0–100 с объяснением недостающих полей и уровнями карточки.
- Публикация при рейтинге от 60 и заполненных обязательных полях.
- Каталог, отсортированный по рейтингу качества.
- Отклик команды и ручной выбор бизнесом; после выбора новые отклики закрыты.
- Сохранение данных в `data/tasks.json` между перезапусками.
- Вкладка регистрации бизнеса и команд: профили в `data/users.json`, пароли
  хешируются с индивидуальной солью (scrypt); повторный email не допускается.
  Регистрация пока не создаёт сессию: вход и проверка прав ещё не реализованы.

## Демонстрация

1. Во вкладке «Бизнес» создайте короткий черновик и посмотрите подсказки рейтинга.
2. Дополните проблему, результат, критерии успеха, ресурсы и срок.
3. Опубликуйте задачу, переключитесь в «Каталог» и отправьте отклик команды.
4. Вернитесь в «Бизнес» и выберите эту команду.

Это локальный прототип: вкладки имитируют роли, авторизации и разграничения доступа
пока нет. Все задачи и отклики общие. Не используйте реальные персональные данные.
Сервер по умолчанию слушает только `127.0.0.1`; перед публичным размещением нужны
авторизация, проверка владельца задачи и настоящая БД. AI-помощник пока не реализован:
текущий рейтинг детерминированный и проверяет полноту, а не достоверность описания.
