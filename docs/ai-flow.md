\# AI Flow



\## Goal



AI helps a business turn an incomplete task description into a structured task card.



\## Flow



Business draft

→ FastAPI

→ OpenAI API

→ LLM analysis

→ Structured output

→ Clarification questions

→ Business answers

→ Editable task card

→ Human confirmation



\## AI responsibilities



\- Analyze the initial business task description

\- Detect missing information

\- Generate at least 3 relevant clarification questions

\- Transform provided information into a structured task card

\- Never invent information that the business did not provide



\## Structured output



Example:



{

&#x20; "missing\_fields": \[

&#x20;   "users",

&#x20;   "data\_and\_materials",

&#x20;   "success\_criteria"

&#x20; ],

&#x20; "questions": \[

&#x20;   "Who will use the solution?",

&#x20;   "What data is currently available?",

&#x20;   "How will success be measured?"

&#x20; ]

}



\## Rating



The readiness score is NOT generated by the LLM.



It is calculated by deterministic application logic using the task fields and the scoring rules.
