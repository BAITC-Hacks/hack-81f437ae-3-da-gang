# План команды на 5 часов

| Время | Результат |
|---|---|
| 0:00–0:30 | Запустить каркас, согласовать сценарий, выбрать пример бизнес-задачи |
| 0:30–1:45 | AI-уточнения и улучшение карточки; улучшение форм и подсказок |
| 1:45–2:45 | Каталог, отклики, кабинет бизнеса, ручной выбор команды |
| 2:45–3:45 | Интеграция, роли/хранение по необходимости, обработка ошибок |
| 3:45–4:30 | Проверка полного сценария и оформление демо |
| 4:30–5:00 | Репетиция питча, резервная демонстрация, финальная проверка |

## Разделение работы на 3–5 человек

1. Интерфейс: `public/`, адаптивность, формы, понятное отображение рейтинга.
2. Backend: `src/server.mjs`, `src/storage/`, роли и сохранение.
3. AI и бизнес-логика: `src/domain/`, уточняющие вопросы, критерии оценки.
4. При наличии участника: тестирование и сценарий демонстрации.
5. При наличии участника: дизайн, примеры задач и питч.

Сначала договоритесь о полях API; каждому участнику — своя ветка и небольшие коммиты.

## Приоритеты

Обязательно: черновик → качество → публикация → отклик → выбор команды.
Следом: AI превращает свободный текст в предложение карточки; бизнес подтверждает.
Если останется время: фильтры, рекомендации по навыкам, история улучшения рейтинга.
Рекомендации не должны автоматически назначать команду.

## Демонстрация на 3 минуты

- 0:00–0:40: бизнес вводит расплывчатую задачу и видит низкий рейтинг.
- 0:40–1:30: дополняет карточку по подсказкам, получает высокий рейтинг, публикует.
- 1:30–2:15: студенческая команда находит задачу и предлагает подход.
- 2:15–3:00: бизнес просматривает отклик и выбирает команду.

Не обещать AI-возможности, пока они не подключены. В текущем каркасе подсказки
правиловые, роли переключаются в интерфейсе без входа.
